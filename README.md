# GREENDOME

Site vitrine et catalogue de GREENDOME — bulles transparentes haut de gamme, jacuzzis et maisons en kit.

## Stack

- Vite + React 18 + TypeScript
- Tailwind CSS + shadcn-ui
- Framer Motion
- React Router

## Démarrer en local

```sh
bun install
bun run dev
```

Le serveur tourne sur [http://localhost:8080](http://localhost:8080).

## Build production

```sh
bun run build
```

Le résultat est dans `dist/`, prêt à être déployé sur n'importe quel hébergeur statique (Vercel, Netlify, OVH, hébergement WordPress avec sous-domaine, etc.).
